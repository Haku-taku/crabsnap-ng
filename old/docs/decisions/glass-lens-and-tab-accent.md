# ADR: 透镜罩在内容之上，内容不缩放；选中态穿强调色

状态：**已采纳并实现**（2026-11-03）。代码在 `ui/crates/ui-widgets-glass/src/tab_bar.rs`、
`segmented.rs`，强调色角色 `glassSelectionAccent` 在 `pack.rs`。

## 旧做法与问题

1. **标签按「离透镜多远」连续放大 1.0–1.15**（`MAGNIFY`）：玻璃块移动时每个标签都在改尺寸，
   静止时选中项也比别的大。这是我们自己的发挥，参考只按鼓起程度缩放。
2. **为了避开重采样，一度把透镜挪到内容之下。** 结果玻璃不再折射标签，丢了液态玻璃的
   签名效果；而且内容仍应在玻璃下，要解决的是「内容自己缩放」，不是「玻璃罩着内容」。

## 改用什么

- 叠放：胶囊/轨道 → 静止指示片 → 标签 → **强调色副本** → 透镜。透镜回到内容之上。
- 删除 `MAGNIFY` 与任何显式内容缩放：标签尺寸恒定，只剩透镜自身的光学缩放
  （`capture_size: 1.1`，即显示范围比捕获小 10%）。
- **标签栏的选中项**：整行按强调色（HIG `tintColor`）再画一遍，按透镜的圆角矩形裁切，
  画在透镜之下。玻璃罩住的那部分文字与图标因此是 accent，行本身仍是中性墨色。参考的
  分段控件用同一招（`segmented_control_internal.dart:368-390`），标签栏用「未选中行反向
  裁切 + 选中行正向裁切」（`tab_bar_bottom_internal.dart:945-1035`）。裁切范围就是透镜
  本身：透镜按 1:1 显示身下的内容，边缘不会读到节点之外（见 `glass-capture-mapping.md`），
  副本因此不必外扩，也不会露到玻璃外面。
- **分段控件的选中项**不是文字染色，而是整枚指示片一层强调色：静止片上加一层
  `SEGMENT_ACCENT`（28%）的洗色。这层颜色只属于常规态——玻璃鼓起时它随静止片一起淡出，
  透镜材质的 `tint`（`SEGMENT_LENS_TINT` 22%）同样按 `rest_fade(thickness)` 淡到 0，
  因此玻璃态是通透的，不染色。

## 哪条检查抓回归

- **没有自动化检查**。手工判据：`GALLERY_PAGE=nav-bar` 把透镜停在 Home 与 Search 各截
  一帧 —— 透镜里的标签是 accent、外面是中性；两行字形逐像素对齐，标签包围盒不随透镜移动。
- 分段控件：`GALLERY_PAGE=segmented` 点另一个分段，整枚指示片（含图标带）带 accent 移动，
  文字只有字重/墨色按设计过渡。
