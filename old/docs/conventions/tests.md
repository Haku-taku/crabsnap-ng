# 测试规范

> `AGENTS.md` §7 的完整版。要点：**每条测试都是可被读者证伪的行为主张**；
> 先让它红，再让它绿。小节号对应 `AGENTS.md` §7.1–§7.6。

## 1. 指导原则

一条测试是**读者读完就能证伪的行为主张**。如果主张不能从测试名与测试体看出来，
这条测试是伪装成安全网的文档债。

**每条新测试都必须在评审里回答三问：**

1. **它钉住了哪个不变量？**（写进测试名）
2. **什么改动会让它失败？**（说不出来就不是测试）
3. **为什么现有测试抓不到？**（能抓到就扩展那一条，别新增）

任何一问的答案是"将来某天能防回归"，**就不要加这条测试**。

## 2. 不要加的

| 反模式 | 拒绝理由 |
|---|---|
| "覆盖每个公开方法" | 断言的是实现形状，不是行为；无害重构就会红 |
| 默认加跨模块集成测试 | 慢、不原子，失败指不到任何单个单元。只有**交互本身**是不变量时才加 |
| 给平凡输出加快照/e2e | 没人读的快照是橡皮图章 |
| 用同一个常量重新断言自己 | `assert_eq!(MAX, 24)` 而 `MAX = 24`——同义反复 |
| 为"提高覆盖率"加的测试 | 覆盖率是好测试的结果，从来不是目标 |
| 同一层写两遍 | 选一层（通常是能表达该不变量**最低**的那层） |
| 需要 GPU / Wayland / 真实时钟的测试 | 不确定；留在 `examples/` 当人工诊断 |

## 3. 要加的——原子性规则

- **一条测试一个行为。** 三个 arrange/act 块就是三条测试穿一件外套——拆开，
  除非**这个序列本身**就是不变量（状态机）。
- **不共享可变夹具。** 每条测试自己构造最小世界。助手函数可以；带隐藏状态的助手不行。
- **只喂确定输入。** 不用墙钟（`Instant::now`）、不用无种子的 RNG、不碰文件系统/网络/环境变量。
  时间与端口作为参数注入。
- **断言那个东西，不是它的代理。** 断言返回的矩形，不是"函数被调用了"。
- **名字就是规格。** `pad_widens_beyond_the_dirty_rect` 胜过 `test_effect_2`。

## 4. 各类测试放哪

| 层 | 位置 | 可以覆盖 |
|---|---|---|
| 单元 | 所属 crate 内 `#[cfg(test)] mod tests` | 一个函数 / 一个类型的契约 |
| 属性 / 差分 | 同一 crate | "增量结果 == 全量结果"这类不变量，有种子、可复现 |
| 跨 crate 契约 | `crates/<focused>/tests/`（少用） | 仅当**两个 crate 之间的契约**是主题 |
| 视觉 / 人工 | `examples/*` | 任何需要 GPU、compositor 或人眼判断的东西 |

原子测试是**只为一个原因失败**的测试。一条红测试让你打开三个文件才能判断哪里坏了，它就不原子。

## 5. 修改或删除测试

删掉低价值测试是正常的、被批准的动作——在提交信息里说一声。不要因为"它一直在那儿"就保留。
永远不要为了让重构通过而弱化断言；要么重构错了，要么断言错了——判断是哪一个，并记录下来。

## 6. 测试评审清单（对每条新增/修改的测试执行）

- [ ] 名字陈述了它保护的不变量
- [ ] 只有一个失败原因
- [ ] 无 IO、无时钟、无 RNG、无环境变量
- [ ] **因正确的原因失败**（临时破坏代码验证过，然后恢复）
- [ ] 不能被常量折叠的同义反复满足
- [ ] 位于能表达该不变量的最低层
- [ ] 别处没有覆盖过
